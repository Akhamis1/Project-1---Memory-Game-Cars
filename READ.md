# Car Memory Match

## Technologies Used

- HTML
- CSS
- JavaScript

## Description

Car Memory Match is a card game using different car brands.

The player flips two cards and tries to find matching cars. Matching cards stay open, while wrong cards turn back over.

The player wins by matching all cards and loses after 10 wrong guesses.

## User Stories

- As a user, I want to flip car cards.
- As a user, I want matching cards to stay open.
- As a user, I want to see my wrong guesses.
- As a user, I want to restart the game.
